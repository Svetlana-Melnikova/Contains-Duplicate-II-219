## Задача

Даны список целых чисел `nums` и число `k`. Нужно вернуть `True`, если в списке есть два одинаковых числа на разных позициях и расстояние между их индексами не превышает `k`. Если такой пары нет, нужно вернуть `False`.

## Решение

В файле `contains_duplicate_ii.py` задача решена методом `containsNearbyDuplicate` класса `Solution`. Я один раз прохожу по списку через `enumerate`, получая индекс и значение каждого элемента. В словаре `numbers` я храню последний просмотренный индекс каждого числа.

Если текущее число уже есть в словаре, я проверяю расстояние до его предыдущего появления. Если расстояние не больше `k`, возвращаю `True`. В остальных случаях сохраняю текущий индекс и продолжаю обход. Если весь список просмотрен и подходящей пары нет, возвращаю `False`.

## Почему это работает

До проверки текущего элемента в словаре хранятся индексы только уже просмотренных элементов. Поэтому найденная пара всегда состоит из двух разных позиций.

Последнее появление числа находится ближе всего к текущему индексу среди всех его предыдущих появлений. Если даже оно дальше, чем на `k` позиций, более ранние появления тоже не подходят. Поэтому для каждого числа достаточно хранить только последний индекс.

## Сложность

- Время — **O(n)** в среднем. Я прохожу по списку один раз, а поиск и запись в словаре в среднем занимают O(1).
- Дополнительная память — **O(n)**. Если все числа разные, в словаре может быть до `n` записей.

## Примеры

| `nums` | `k` | Результат |
|---|---:|---|
| `[1, 2, 3, 1]` | 3 | `True` |
| `[1, 0, 1, 1]` | 1 | `True` |
| `[1, 2, 3, 1]` | 2 | `False` |
| `[1, 1]` | 0 | `False` |
